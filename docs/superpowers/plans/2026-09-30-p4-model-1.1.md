# P4 Model 1.1 Implementation Plan (v1.2.0; models `1.1.0` / `cfb-1.1.0`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Tasks are strictly sequential: the baseline must be committed before any feature change. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retrain both models with in-season signals (season-to-date margin and efficiency that never cross a season boundary), a neutral-site flag, and a has-a-real-line flag. Ship each sport only if it beats its own 1.0 baseline.

**Architecture:** Six new columns go into `FEATURE_COLUMNS`:
- `season_margin_diff`, `season_epa_off_diff`, `season_epa_def_diff`: shrunk toward 0 by 3 phantom games
- `season_games_min`
- `is_neutral_site`
- `has_market_line`: moved out of metadata

Old bundles keep working because `predict_week` selects each bundle's own `feature_columns`. Training windows are unchanged (`TRAIN_SEASONS = [2022, 2023, 2024]`, `CALIB_SEASON = 2025`), so the backtest isolates the feature change. Prediction rows are stamped with the loaded artifact's own `model_version`.

**Tech Stack:** pandas, xgboost, scikit-learn (pinned versions only), pytest.

**Spec:** [`docs/superpowers/specs/2026-09-30-booth-data-model-1.1-design.md`](../specs/2026-09-30-booth-data-model-1.1-design.md) (findings F5 and F6; decision 6, the per-sport gate).

## Global Constraints

Everything in the spec's **Global constraints** applies. Most relevant:
- **Leakage rule:** every new feature uses only games strictly before kickoff. The existing leakage test iterates `FEATURE_COLUMNS`, so it covers the new columns automatically. It must stay green.
- **Gate (decision 6):** a sport ships 1.1 only if its pooled ("All") walk-forward Brier **and** log loss are both less than or equal to its 1.0 baseline from Task 1. A sport that fails keeps its 1.0 artifact, its `latest.json`, and its version string.
- **Pinned dependencies:** never upgrade xgboost or scikit-learn here.
- **Committed models:** whitelist each new `.joblib` in `.gitignore`, and keep the 1.0 artifacts committed for rollback.
- Git authorship is the maintainer's only, with no AI attribution. Production writes need the maintainer's go-ahead. Backtests and training only **read** the production DB, which is allowed.

Branch: `git checkout -b ct/feat/model-1.1` off an up-to-date `main` (P1, P2 and P3 merged).

```python
# Season-to-date form is shrunk toward zero by this many phantom average games,
# so one blowout in week 1 doesn't read as a full season's evidence.
SEASON_SHRINK_GAMES = 3.0


def _season_to_date(games: pd.DataFrame, stats: pd.DataFrame) -> pd.DataFrame:
    """Post-game season-to-date form per (team, season, played game). Unlike
    _team_form this never crosses a season boundary."""
    played = games[games["home_score"].notna() & games["away_score"].notna()]
    cols = ["game_id", "season", "kickoff", "team_id", "pts_for", "pts_against"]
    home = played[["game_id", "season", "kickoff", "home_team_id", "home_score", "away_score"]]
    away = played[["game_id", "season", "kickoff", "away_team_id", "away_score", "home_score"]]
    long = pd.concat(
        [home.set_axis(cols, axis=1), away.set_axis(cols, axis=1)], ignore_index=True
    )
    long = long.merge(
        stats[["game_id", "team_id", "epa_offense", "epa_defense"]],
        on=["game_id", "team_id"],
        how="left",
    )
    long["margin"] = long["pts_for"] - long["pts_against"]
    long = long.sort_values(["team_id", "kickoff"])
    grouped = long.groupby(["team_id", "season"], sort=False)
    long["n"] = grouped.cumcount() + 1.0
    long["margin"] = grouped["margin"].cumsum() / (long["n"] + SEASON_SHRINK_GAMES)
    for side in ("offense", "defense"):
        col = f"epa_{side}"
        total = grouped[col].transform(lambda s: s.fillna(0.0).cumsum())
        count = grouped[col].transform(lambda s: s.notna().cumsum())
        long[f"epa_{side[:3]}"] = total / (count + SEASON_SHRINK_GAMES)
    return long[["team_id", "season", "kickoff", "n", "margin", "epa_off", "epa_def"]]


def _asof_season(games: pd.DataFrame, season_form: pd.DataFrame, side: str) -> pd.DataFrame:
    """Season-to-date form entering each game; zeros before a team's first game."""
    left = games[["game_id", "season", "kickoff", f"{side}_team_id"]].rename(
        columns={f"{side}_team_id": "team_id"}
    )
    merged = pd.merge_asof(
        left.sort_values("kickoff"),
        season_form.sort_values("kickoff"),
        on="kickoff",
        by=["team_id", "season"],
        direction="backward",
        allow_exact_matches=False,
    )
    values = ["n", "margin", "epa_off", "epa_def"]
    merged[values] = merged[values].fillna(0.0)
    return (
        merged[["game_id", *values]].set_index("game_id").add_prefix(f"{side}_season_")
    )
```
